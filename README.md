# V-G-A Comunidade

Arquivos compartilhados pelos usuários do V-G-A: **BIOS, esquemas, boardviews e fotos** de placas de vídeo.

- Os arquivos em si ficam em **Releases** (cada publicação é uma Release); as pastas `bios`, `esquemas`, `boardview` e `fotos` deste repositório são só organização.
- O catálogo de tudo o que foi enviado está em `catalogo.json`.
- Quem envia declara ter o direito de compartilhar o arquivo.
- Para pedir a remoção de um arquivo (direitos autorais ou problema), abra uma *Issue* neste repositório.

Este repositório é mantido automaticamente pelo programa; não edite manualmente.
